## Repo layout

```
.
├── build.mjs        source of truth — inline React components per scene
├── template.json    generated by build.mjs — what Editor Playground loads
├── render.mjs       reads template.json → MP4 via @rendervid/renderer-node
├── spec.md          scene-by-scene design spec
├── output/          MP4 lives here (gitignored)
└── node_modules/    symlinked @rendervid/core + @rendervid/renderer-node
```

## Workflow

```bash
# 1. Edit a scene component in build.mjs, then regenerate the template:
node build.mjs

# 2. Open Editor Playground (rendervid workspace) and hit Load → template.json:
#    http://localhost:5180/

# 3. When you're happy, render the MP4:
node render.mjs
```
